Install on Android / Build APK PWA Ready

Option 1: Direct Android / iOS Install (No APK needed)

Open this page in Chrome on Android (tap ⋮ Menu → Add to Home screen / Install app) or Safari on iOS (Share → Add to Home Screen). It launches full-screen offline like a native app.

Option 2: Generate a Standalone `.apk` File

Because browser sandboxes cannot compile binary `.apk` files directly, click Save HTML above, then upload `index.html` to a free Web-to-APK wrapper (such as WebIntoApp.com, AppsGeyser, or Capacitor/Cordova) to get your signed `.apk` in 30 seconds.
